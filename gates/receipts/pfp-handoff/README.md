# Actual overlapping-PFP handoff to v10 — fixture qualification

No corpus ladder or performance promotion. Source: `xsa/runtime/pfp/{parse,rows}.cpp` and the helpers they call. The old `stream_keys -> stream_rank -> stream_rows` receipts are not measurements of this path.

* `python3 -BE xsa/tests/pfp_parse.py BUNDLE/pfp_parse BUNDLE/stream_rank` checks dense lexical IDs, first references, frequencies, histogram, and the integer suffix-rank recurrence. The historical 71-byte counterexample yields starts `[0,11,27,43,59]`, tape `[0,2,2,2,1]`, refs `[(0,11,1),(59,12,1),(11,16,3)]`. Also checked: 1..7 bytes, final-window and overlapping hits, binary bytes, a 65,537-byte uncut phrase, worker invariance, insufficient scratch, all-symbol refusal. The 320,000-comma naming stress case uses a 512 KiB naming workspace and ample test scratch to force an intermediate external phrase merge; it is **not** a 2N result for that adversarial density.
* `python3 -BE xsa/tests/pfp_rows.py BUNDLE` checks every position, adjacent LCP and predecessor against an independent byte suffix sort (only in the oracle), including position 0 / 256, END at N, and equal representatives belonging to different words. The same 8,192-byte binary fixture at two workspace grants: **2 → 16** exact ranges; **8,192 counted, 8,192 routed, 8,192 loaded for ordering** for each run; 8,193 exact rows. These are loop counts over owned dictionary offsets, not inferred from an index checksum. Also passed with ASan+UBSan on the naming and row producers.
* `python3 -BE xsa/tests/build_stream.py XSA` checks the public command, boundary-aware m20, m15, quiet success, no overwrite, deterministic product, downstream failure/cancellation and scratch cleanup. `python3 -BE gates/pfp_generated_v10_test.py XSA` recreates the generated input and XSEP map and checks the **whole product after publication** against the [older trusted pin](../build-stream/generated.json).

Not qualified here: recursive ranking of the integer tape, fit of the rank view below corpus size, oversized two-symbol cell refinement, physical scratch at scale, or speed versus a matched resident build. No raw `xsa build` default was switched on fixture evidence.
