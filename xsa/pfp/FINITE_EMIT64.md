# From routed distinct offsets to ordered byte suffix rows

`finite_emit64` takes raw + certified inverse, builds the [aligned view](RAW_RANK_VIEW64.md) and [posting index](FINITE_ROUTE64.md), and writes row43 **only to a pipe**. It starts with END at `N`, LCP 0, predecessor `text[N−1]`; suffix 0 has predecessor 256. No row file, no all-byte SA, LCP or dictionary mapping. Standalone binary does not by itself certify its output. The consumer must validate all rows against raw. Transport checks `<2^43`; format is not an unlimited-u64 contract.

* Lexical work units are **whole finite-key ranges**. Admit an eight-byte arena slot per distinct offset currently in flight, not per occurrence. Where checked widths permit, pack head rank and offset, otherwise use the page token. Spare high bits cache a monotone projection; equal projections always compare actual bounded keys, never source positions as a lexical tiebreak. EOF exhaustion sorts before a following data byte, including a real NUL. A differing ordinary key cannot be a proper prefix of another: its ending trigger would have stopped that other word too.
* A band above the slot cap is **not loaded whole**. Read its compressed postings, measure the common prefix and next-code histogram, resetting the previous mass to the witness code whenever the common prefix shrinks. Coalesce consecutive whole codes that fit. Recursively split only deficient intervals (iterative stack). Each filter covers the full shared byte prefix and a contiguous next-code interval. An oversized class that is *exactly equal* bypasses the sort arena altogether. Charge every scan for the **entire coarse band** it decodes, not just survivors; refuse before publishing END above `16U` post-index decodes or 16,384 leaves/active planning entries. This is a bounded **local replay** policy, not constant work for all possible inputs.
* **Single-descriptor group:** the head's list is already in successor order. Emit `position(r)+offset`; after the first occurrence, LCP is `adjacent_aligned_lcp(r)−offset` because the two aligned starts are consecutive in that list. The first row uses the preceding finite group's byte LCP.
* **Equal tails from different words:** let their common finite length be `L` (ordinary, `L>8`). Every occurrence has a unique successor `s`. Its suffix starts at `position(s)−(L−8)`, **irrespective of which representative supplied it**. Hence we need *only the union of successor ranks*, not a cursor per descriptor and not a table of `(rank,position)` tuples. For ≤16 occurrences sort a tiny inline array. Otherwise set successor bits, with another bitmap marking nonempty words at each level up to the root. Traverse in increasing rank and clear only touched words. After the first row the byte LCP is `L−8 + aligned_LCE(prev_s,s)` (use the stored adjacent value if consecutive). Reject duplicate continuation bits. Bitmap payload is `8*sum(ceil(m/64^j), j=1..root)` per live lane; no multiplicity cutoff and no full-universe clearing pass per class. More members still cost more **work**.
* Up to four independent sort/expansion lanes, with a **single** total slot budget across each wave. Each has its own three-packet, 2,048-row-per-packet ring. Between waves keep just the preceding last finite span for the seam. The first LCP of each range is computed by comparing that span with the current first key. The publisher simply drains complete packets in band order; no row merge comparisons. Use nonblocking pipe writes and STOP/deadline polls even if the sink stalls. `cat_wait_s`, `cat_send_s`, EAGAIN/successful writes, lane queue-full time and wave clocks are distinct and can overlap.

### Evidence and remaining limits

`gates/overlap_finite_emit64_test.py` compares complete little-endian row bytes to independent byte suffix doubling + byte Kasai on generated binary texts at 1/2/4 workers. The 116,362-byte constructed input has 8,311 distinct ordinary words sharing a nine-byte tail. It produces the correct stream even with **8,192 slots**, including the exact-class bypass. The separate bitmap unit drains 546,044 shuffled successor ranks twice in the real 10 GB rank universe; this unit is not a measured real 546k-word tie. UBSan and the small route proofs passed. First fixture compiler exit (`proc_886c`, `-Winfinite-recursion` on the empty-drain test specialization) led to a bounded iterative traversal; first emitter (`proc_f277`) correctly refused a >20,000-descriptor two-code band in the constructed input. Added local refinement and kept the original arena limit; did not promote that refusal into a successful stream.

`finite_emit64 plan 100000000000 3181334488 1 100000000000 577 192000000 4` reports a **149,889,337,624 B** conservative producer array upper including raw, posting navigation, four successor bitsets, **192 million total slots** and bounded rings/controls. Only **434,517,736 B** below 140 GiB. Requires the measured 100 GB band count at the fixed `ceil(N/1024)` target; not permission to add an arbitrary run sorter. The separate file bound is ≤166,448,027,569 B including private inverse and margin while routing/emitting. The 10 GB archived distinct histogram implies at least 3.72 full-U-equivalent post-index decodes at the matching 19.2M slots for this local replay scheme (including a split scan per deficient band; its measured largest tie is smaller than the arena). No 100 GB wall claim, guaranteed `16U` success, certified shared-cache/finish/verifier fit or index product.
