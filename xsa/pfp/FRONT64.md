# Direct, parallel raw → wide lexical columns

`tools/front64.cpp` builds **both** inputs for the 64-bit route. `dictionary.lex64` consists of `[u64 LE (raw_length<<1 | EOF), raw bytes]` records in strict `(raw,EOF)` lexical order. `keys.u64[j]` is the actual **byte address of the record header** of occurrence j in that file. Zero is a valid address; no sentinel is stolen from the keys. Length tagging leaves 63 length bits, consistent with signed 64-bit filesystem extents. Text offsets, occurrence ordinals, group/extent counts, prefix sums, cached lexical prefixes, lengths, assigned addresses and key wire are 64-bit. Grant arithmetic uses u128. Raw bytes, histogram digit, booleans and CPU indices needn't be 64-bit storage. No legacy dictionary or dense u32 IDs in the builder or [downstream ranker](PARSE64.md).

```
g++ -std=c++20 -O3 -Wall -Wextra -Werror -fopenmp xsa/pfp/tools/front64.cpp -o front64
front64 plan N M THREADS
front64 RAW NEW_DIRECTORY THREADS ARRAY_GRANT_BYTES SCRATCH_BYTES STOP_PATH DEADLINE_UNIX
parse64 rank NEW_DIRECTORY/keys.u64 NEW_INVERSE.u64 THREADS RANK_ARRAY_BYTES STOP_PATH DEADLINE_UNIX
```

* Split candidate trigger **starts** `1..=n-8` among lanes. The eight bytes may cross the lane cut. Count, exclusive-prefix the lane masses after the single mandatory start at zero, and fill disjoint text-order start slots in a second pass. Consecutive starts determine owned length; append exactly eight lookahead bytes except at the unique EOF. No overlap dedup heuristic or cutpoint patching.
* Cache the leading eight raw bytes (unsigned, zero-padded only for the cache). Histogram the top 12 bits per lane and assign disjoint destinations for `(prefix,ordinal)` entries. Local orders compare the **full** trailing bytes, lengths and terminal tag as necessary. Equal records necessarily route to the same bin. Dynamic scheduling across bins; the largest bin can limit parallelism. No equality based on a hash or just the prefix.
* Find distinct records and **relative** byte addresses in each bin, reusing the no-longer-needed prefix field. Prefix-sum 4,096 byte counts, then `pwrite` final, disjoint contiguous dictionary ranges concurrently. No file concatenation or merge pass. Once raw spans are no longer needed, scatter final addresses back into the **same** starts allocation by original text ordinal. Stream the contiguous key column, fsync both files and the directory, atomically publish without replacement. Partial outputs remain private on refusal/error.

**Limits.** Resident random access to raw bytes is the trade: `N+8(m+1)+16m+4 MiB+2 MiB/worker` provision including the input mapping. Account page cache, runtime and verifier separately.
