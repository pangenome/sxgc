# Production PFP columns (private scratch)

`pfp_parse RAW EMPTY_DIR WORKERS SORT_BYTES SCRATCH_BYTES` is a native bundle stage, not a new `xsa` command. RAW is the exact immutable byte stream. The byte-level trigger is [`xsa_pfp::trigger`](../xsa/runtime/rolling/pfp_trigger.hpp). Positive starts include every matching complete 8-byte window, including the last complete window. There is always a start at 0. No length cap, suppression, or document split. `[p,q)` owns `q-p` bytes; a nonterminal phrase references `[p,q+8)`. The terminal phrase has a virtual END after its last raw byte.

| File | LE wire | Meaning |
|---|---|---|
| `parse.u64` | `m` × u64 | Dense, zero-based lexical phrase IDs **in original text order**, accepted directly by `stream_rank inverse` |
| `phrases.ref` | `k` × `(u64 start, u64 stride, u64 count)` | In lexical ID order. Start = first occurrence, stride = owned length, count = exact frequency. `start+stride==N` identifies the unique terminal word, not `start+stride+8==N`. |
| `histogram` | 256 × u64 | Raw byte counts for the v10 encoder |

There is one sequential trigger scan, not necessarily only one disk read of each byte. A bounded batch of `(position,stride,ordinal)` records is ordered by the **finite** referenced phrase bytes and terminal convention, with ordinal as a deterministic last tiebreak. Hashes choose anchors, never equality. Lexically merge sorted *phrase-reference* runs when the batch fills. Adjacent equal words assign one ID; scatter that ID by ordinal, count its occurrences and write one reference. No copied phrase bytes, raw-suffix run files, or byte suffix array. Long comparisons use bounded caches into RAW.

The comparator caches, batch, merge fan-in, scatter pages and I/O buffers are sized before sorting. An exact logical scratch ledger covers output columns and temporary runs (24 bytes per live occurrence per run generation); it refuses before exceeding the caller's grant. A dense u64 tape can itself exceed 2N on very frequent triggers: this is a refusal, **not** permission to change the parse. Scratch length is not an XFS quota or cgroup RAM measurement. The stage works inside a caller-owned private directory; failure of any stage must prevent publication and the caller removes private files.

## Recursive ID levels

`pfp_parse ids P EMPTY_DIR WORKERS SORT_BYTES FREE_SCRATCH_BYTES` uses the same naming code over **whole LE u64 symbols**. The width is eight IDs; the fixed predicate xors each numeric ID into the wrapping 64-bit hash before multiplying, modulo 31. It does not slide over individual bytes of the ID encoding. Comparison is unsigned numeric lexicographic order, not `memcmp` on little-endian words. Positions and strides in the child refs are **symbol ordinals in P**. In place of the byte histogram there is a 40-byte `census` (five LE u64s: lower length `n`, upper length `m`, upper dictionary size `k`, sum of distinct owned strides `U`, largest input ID).

The private driver measures a next level for tapes of at least 16 symbols, unless all first symbols are unique and the direct kernel fits. It descends on a contraction (`2 <= m <= n/2`) if the directly planned kernel exceeds the array grant **or** `U+m < n`, with room for the simultaneous child columns, postings and lower inverse. The latter inequality compares dictionary offsets + top positions to lower positions; it is a work heuristic, **not** a prediction of IO or wall time. Retire an unselected trial before sorting the leaf. There is no public level switch. A failed selected stage fails the build, not a retry with a different sorter.

`pfp_lift P CHILD_DIR NEW_INVERSE WORKERS SORT_BYTES FREE_SCRATCH_BYTES` consumes `Q`, its refs/census and `inverse(Q)`. It computes occurrence starts by summing strides, and indexes them and their next ranks **by the supplied upper rank**. Word frequencies delimit the contiguous occurrence lists. Count each distinct word's owned offsets by high bits of the first ID, form disjoint ranges from exact counts, and route `(word,offset)` postings once. Sort finite representatives within a range; a single representative's list is already ordered, and equal representatives merge their sorted heads by next rank. Scatter ranks 1..n to original P ordinals. No SA of P is sorted during the lift, no raw corpus argument, no per-range dictionary walk. `FREE_SCRATCH_BYTES` already excludes every live ancestor and child column; lift needs `16U` posting bytes plus `8n` output bytes. Caches on P and the output and simultaneous sort arenas are dial-bounded. The lift admits or refuses its upper tables and largest indivisible ID cell explicitly. `PFP_LIFT` reports offsets counted/routed/ordered separately from positions ranked.
