## Conditional cost model

- Weighted two-candidate mean: 23.701484 symbols/B run; sampling standard error 0.124027.
- Weighted largest candidate mean: 15.021292 symbols/B run.
- At R=4.8e11 and one comparison stage: 1.13767e+13 two-candidate symbols.
- At hypothetical sustained 1e8 / 1e9 symbol comparisons per second: 1.317 / 0.132 days, excluding all other work.
- Actual selection used 27.023 LCE calls and 2.885 hash equality probes/B head; weighted search-only LCE sum 106.164.
- Linear scaling of this fragment implementation's measured query rate alone: 30.336 single-core days.
- Queries exceeding full direct verification: 0; candidate comparisons touching a local seam: 4.
- Immediate phrase shortcuts cover 0.06026% of candidate pairs and 0.302% of total candidate LCE symbols; next-phrase bytes cover 0.348% separately (overlap prevents adding these).
- If a boundary records zero >1M observations, its one-sided 95% event-probability bound is 2.9957278e-06 under IID uniform B-run sampling.

These numbers are conditional arithmetic, not a pile runtime prediction.
All sampled LCE answers were fully directly verified.
Sampling error does not cover corpus shift, a missed heavy tail,
or endpoint/row differences. There is no distribution-free tight upper bound
on the mean from this sample. Pair observations are correlated; confidence
calculations use the sampled B head as the unit. Fragment local cycles do
not certify concatenation order. Output run splitting and all merge levels
must be charged separately. See `DESIGN.md` for the statement lock.
