## Conditional cost model

- Weighted two-candidate mean: 23.877643 symbols/B run; sampling standard error 0.282237.
- Weighted largest candidate mean: 15.191463 symbols/B run.
- At R=4.8e11 and one comparison stage: 1.14613e+13 two-candidate symbols.
- At hypothetical sustained 1e8 / 1e9 symbol comparisons per second: 1.327 / 0.133 days, excluding all other work.
- Actual selection used 27.023 LCE calls and 2.892 hash equality probes/B head; weighted search-only LCE sum 106.340.
- Linear scaling of this fragment implementation's measured query rate alone: 29.298 single-core days.
- Queries exceeding full direct verification: 804; candidate comparisons touching a local seam: 3.
- If a boundary records zero >1M observations, its one-sided 95% event-probability bound is 1.4978549e-05 under IID uniform B-run sampling.

These numbers are conditional arithmetic, not a pile runtime prediction.
Sampling error does not cover corpus shift, a missed heavy tail, hash collisions,
or endpoint/row differences. There is no distribution-free tight upper bound
on the mean from this sample. Pair observations are correlated; confidence
calculations use the sampled B head as the unit. Fragment local cycles do
not certify concatenation order. Output run splitting and all merge levels
must be charged separately. See `DESIGN.md` for the statement lock.
